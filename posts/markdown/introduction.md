Markdown 支持行引言和块引言。

## 行引言

行引言的语法是在行前插入 `>`，然后接空格和要引言的内容。引言内部是支持其他 Markdown 格式的。

- Markdown

```md
> 这是一行引言

> - 引言内也支持其他格式，比如列表、**粗体**、_斜体_、标题等
```

- 渲染效果

> 这是一行引言

> - 引言内也支持其他格式，比如列表、**粗体**、_斜体_、标题等

## 块引言

块引言是指将文档中的「一块内容」进行[行引言](#行引言)，包括空行。块引言允许阶层，你可以创建多层引言。

- Markdown

```md
> 这是一段块引言。
> 可以换行，也可以只在第一行加 `>`。
>
> 空行前面也要带 `>`，否则引用会断开。

> > 两层嵌套引用。
```

- 渲染效果

> 这是一段块引言。
> 可以换行，也可以只在第一行加 `>`。
>
> 空行前面也要带 `>`，否则引用会断开。

> > 两层嵌套引用。

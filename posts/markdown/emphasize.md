Markdown 支持强调语法，包含了粗体、斜体。

## 粗体

粗体的语法是将要粗体的内容使用两个星号 `**TEXT**` 或两个下划线 `__TEXT__` 包围，推荐使用星号：

- Markdown

```md
Markdown 支持**粗体**语法
```

- 渲染效果

Markdown 支持**粗体**语法

## 斜体

斜体的语法是将要斜体的内容使用一个星号 `*TEXT*` 或一个下划线 `_TEXT_` 包围，推荐使用星号：

- Markdown

```md
Markdown 支持*斜体*语法
```

- 渲染效果

Markdown 支持*斜体*语法

## 特性

1. 强调语法不能跨行或跨段使用
2. 代码、代码块中不支持强调语法
3. 引言中支持强调语法

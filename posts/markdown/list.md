Markdown 支持无序列表和有序列表。

## 无序列表

无序列表使用减号 `-` 作为列表标记（也可使用星号 `*`、加号 `+`，通常不建议使用）：

- Markdown

```md
- 列表项 1
- 列表项 2
- 列表项 3

* 列表项 1
* 列表项 2
* 列表项 3

- 列表项 1
- 列表项 2
- 列表项 3
```

- 渲染效果

- 列表项 1

- 列表项 2

- 列表项 3

* 列表项 1

* 列表项 2

* 列表项 3

- 列表项 1

- 列表项 2

- 列表项 3

## 有序列表

有序列表使用数字加英文句号 `.` 作为列表标记：

- Markdown

```md
1. 列表项 1
2. 列表项 2
3. 列表项 3
```

- 渲染效果

1. 列表项 1
2. 列表项 2
3. 列表项 3

## 列表的嵌套

列表可以嵌套，即列表项中可以包含列表。要嵌套列表，你需要将下一层列表的标记缩进至上一层的**内容开头**，即：**无序列表缩进 2 空格，有序列表缩进 3 空格**：

- Markdown

```md
- 列表项 1
  - 列表项 1.1
  - 列表项 1.2
- 列表项 2
  - 列表项 2.1
  - 列表项 2.2

1. 列表项 1
   1. 列表项 1.1
   2. 列表项 1.2
2. 列表项 2
   1. 列表项 2.1
   2. 列表项 2.2
```

- 渲染效果

- 列表项 1
  - 列表项 1.1
  - 列表项 1.2

- 列表项 2
  - 列表项 2.1
  - 列表项 2.2

1. 列表项 1
   1. 列表项 1.1
   2. 列表项 1.2
2. 列表项 2
   1. 列表项 2.1
   2. 列表项 2.2

### 避免意外的列表歧义

有时候，列表可能会意外地产生，比如：

```md
1997. 中国文学出版社
```

此时，你可以使用转义字符 `\` 来避免列表的产生。`\` 会告诉 Markdown 解析器，这个 `.` 不是列表项的标记：

- Markdown

```md
1997. 中国文学出版社
      1997\. 中国文学出版社
```

- 渲染效果

1997. 中国文学出版社

1997\. 中国文学出版社

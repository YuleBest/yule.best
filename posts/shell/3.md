## 一、循环语法(`for` 和 `while`)

### 1 `for` 循环

Bash 中的 `for` 循环提供了两种主要的语法形式。

**标准列表遍历式 `for` 循环**：

```bash
for 变量 in 列表
do
  命令序列
done
```

示例：

```bash
# 遍历字符串列表
for fruit in apple banana cherry
do
  echo "I like $fruit"
done

# 遍历文件
for file in *.txt
do
  echo "Processing file: $file"
done

# 使用序列表达式
for i in {0..20..5}  # 从0到20,步长为5
do
  echo "Number: $i"
done
```

**C 风格 `for` 循环**：

```bash
for ((初始化; 条件; 步长))
do
  命令序列
done
```

示例:

```bash
for ((i = 0; i <= 100; i++))
do
  echo "Counter: $i"
done
```

### 2 `while` 循环

`while` 循环是一种**条件驱动**的循环结构：

```bash
while 条件测试
do
  命令序列
done
```

示例:

```bash
# 数值比较
i=0
while [ $i -le 10 ]
do
  echo "Number: $i"
  ((i++))
done

# 使用双括号
while ((i < 10))
do
  echo "Value: $i"
  ((i += 2))
done

# 无限循环
while true
do
  echo "Running forever..."
  sleep 1
done
```

### 3 文件与列表的遍历技巧

**文件遍历**：

```bash
# 正确的文件遍历方法
for file in /path/to/directory/*
do
  if [ -f "$file" ]; then
    echo "Processing file: $file"
  fi
done
```

**数组遍历**：

```bash
fruits=("apple" "banana" "cherry")

# 遍历数组值
for fruit in "${fruits[@]}"
do
  echo "Fruit: $fruit"
done

# 遍历索引和值
for i in "${!fruits[@]}"
do
  echo "Index: $i, Value: ${fruits[$i]}"
done
```

### 4 循环控制:`break` 和 `continue`

**`break` 命令**用于立即终止循环：

```bash
for ((i = 0; i < 5; i++))
do
  for ((j = 0; j < 5; j++))
  do
    if ((i * j == 6))
    then
      break 2  # 跳出两层循环
    fi
    echo "$i * $j = $((i * j))"
  done
done
```

**`continue` 命令**用于跳过当前迭代：

```bash
for file in *
do
  if [ -d "$file" ]; then
    continue  # 跳过目录
  fi
  if ! [[ "$file" =~ \.txt$ ]]; then
    continue  # 只处理txt文件
  fi
  echo "Processing text file: $file"
done
```

### 5 循环变量作用域

**变量的全局特性**：默认情况下，所有变量都是全局的，除非在函数内部使用 `local` 关键字声明。

**子 shell 对变量的影响**：

```bash
# 错误示例:子shell中的修改不可见
count=0
ls | while read -r file
do
  ((count++))
done
echo "File count: $count"  # 输出0

# 正确方法:使用进程替换
count=0
while IFS= read -r file
do
  ((count++))
done < <(ls)
echo "File count: $count"  # 正确输出
```

## 二、重定向和管道

### 1 重定向基础语法与符号

Bash 默认定义了三个标准文件描述符：

- **标准输入(`stdin`)**：文件描述符为 0
- **标准输出(`stdout`)**：文件描述符为 1
- **标准错误(`stderr`)**：文件描述符为 2

**基本重定向操作符**：

```bash
# 覆盖输出重定向
ls > list.txt

# 追加重定向
echo "$(date)" >> log.txt

# 输入重定向
sort < file.txt

# 错误输出重定向
ls non_existent_file 2> error.log

# 同时重定向标准输出和错误输出
ls -l existing_file non_existent_file &> all_output.log
# 等效写法
ls -l existing_file non_existent_file > all_output.log 2>&1
```

### 2 进程替换

**输入型进程替换(`<()`)**：将命令的输出伪装成一个只读文件

```bash
# 比较两个命令的输出
diff <(ls -l) <(ls -l /tmp)

# 统计进程数量
wc -l <(ps -ef)
```

**输出型进程替换(`>()`)**：将命令的输入伪装成一个只写文件

```bash
# 将数据同时发送到两个进程
cat data.txt | tee >(grep "pattern" > results.txt) >(wc -l > count.txt)
```

### 3 Here 文档

Here 文档允许在命令中直接嵌入多行文本输入：

```bash
# 基本语法
command << delimiter
文档内容...
delimiter

# 创建配置文件示例
cat > config.conf << EOF
[server]
host = localhost
port = 8080
[database]
name = mydb
user = root
EOF
```

### 4 管道机制

管道操作符 `|` 用于连接多个命令：

```bash
# 统计当前目录下的文件数量
ls | wc -l

# 查找包含"error"的日志行并统计
grep "error" log.txt | wc -l

# 按大小排序并显示最大的5个文件
ls -lS | head -5
```

### 5 管道与 `xargs` 命令的配合使用

`xargs` 命令用于将管道输入转换为命令行参数：

```bash
# 将find的输出作为rm的参数
find . -name "*.bak" -print0 | xargs -0 rm

# 并行处理(使用4个进程)
find . -name "*.txt" | xargs -P 4 grep "pattern"

# 限制参数个数
ls | xargs -n 5 echo
```

### 6 管道中的错误处理

```bash
# 启用pipefail选项
set -o pipefail

# 执行管道命令
ls non_existent_dir | grep "pattern"
echo $?  # 会显示非零值(错误)

# 条件判断管道结果
if grep -q "pattern" file.txt; then
    echo "Pattern found"
else
    echo "Pattern not found"
fi
```

## 三、文件操作

### 1 文件读取

**`cat` 命令**：

```bash
# 显示文件内容
cat file.txt

# 连接多个文件
cat file1.txt file2.txt > combined.txt

# 显示文件并添加行号
cat -n file.txt
```

**`head` 和 `tail` 命令**：

```bash
# 查看文件前10行
head file.txt

# 查看前20行
head -n 20 file.txt

# 查看文件后10行
tail file.txt

# 实时监控文件(常用于日志)
tail -f log.txt
```

### 2 写入文件

**`echo` 命令**：

```bash
# 写入单行文本
echo "Hello World" > file.txt

# 追加文本
echo "This is a new line" >> file.txt

# 输出转义字符
echo -e "Line 1\nLine 2\tTabbed" > file.txt
```

**`printf` 命令**：

```bash
# 格式化输出
printf "Name: %-10s Age: %3d\n" "Alice" 30 > file.txt
printf "Name: %-10s Age: %3d\n" "Bob" 25 >> file.txt
```

**`tee` 命令**：

```bash
# 将命令输出保存到文件并显示
ls -l | tee file_list.txt

# 追加到文件
ls -l | tee -a existing_file.txt

# 同时写入多个文件
ls -l | tee file1.txt file2.txt file3.txt
```

### 3 文件权限管理

**权限类型**：

| 符号 | 数字 | 文件权限 | 目录权限        |
| ---- | ---- | -------- | --------------- |
| `r`  | 4    | 可读     | 可列出内容      |
| `w`  | 2    | 可写     | 可创建/删除文件 |
| `x`  | 1    | 可执行   | 可进入目录      |

**`chmod` 命令**：

```bash
# 数字模式
chmod 644 file.txt
chmod 755 directory/

# 符号模式
chmod a+x file.sh
chmod u+w file.txt
chmod go-w file.txt
chmod u=rw,g=r,o=r file.txt
```

**`chown` 和 `chgrp` 命令**：

```bash
# 修改文件所有者
chown new_owner file.txt

# 修改文件所有者和所属组
chown new_owner:new_group file.txt

# 递归修改
chown -R new_owner:new_group directory/

# 修改所属组
chgrp new_group file.txt
```

### 4 目录操作

**创建目录**：

```bash
# 创建单个目录
mkdir new_directory

# 创建多级目录
mkdir -p parent/child/grandchild

# 设置目录权限
mkdir -m 750 secure_dir
```

**删除目录**：

```bash
# 递归删除非空目录
rm -r non_empty_directory

# 强制删除(不提示)
rm -rf dangerous_directory
```

**目录导航**：

```bash
# 切换到指定目录
cd /path/to/directory

# 切换到用户主目录
cd ~

# 切换到上一级目录
cd ..

# 查看当前目录
pwd
```

**目录列表**：

```bash
# 列出详细信息
ls -l

# 列出所有文件(包括隐藏文件)
ls -a

# 按修改时间排序
ls -lt

# 按文件大小排序
ls -lS
```

### 5 复制、移动和删除

**复制文件和目录**：

```bash
# 复制文件
cp source.txt destination.txt

# 递归复制目录
cp -r source_dir/ destination_dir/

# 保留文件属性
cp -p file.txt backup/

# 交互式复制
cp -i existing_file.txt new_file.txt
```

**移动或重命名**：

```bash
# 重命名文件
mv old_name.txt new_name.txt

# 移动文件到另一个目录
mv file.txt /new/location/

# 移动目录
mv directory/ /new/location/
```

**删除文件**：

```bash
# 删除文件
rm file.txt

# 递归删除目录
rm -r directory/

# 强制删除
rm -f file.txt
```

### 6 特殊文件操作

**链接文件操作**：

```bash
# 创建硬链接
ln source.txt hardlink.txt

# 创建软链接(符号链接)
ln -s target.txt symlink.txt

# 查看链接
readlink symlink.txt
```

**临时文件的安全创建**：

```bash
# 创建安全的临时文件
tempfile=$(mktemp)
echo "Data" > "$tempfile"
rm "$tempfile"

# 创建临时目录
tempdir=$(mktemp -d)
cd "$tempdir"
# 使用后删除
rm -rf "$tempdir"
```

## 四、总结

通过本章教程，相信你已经基本掌握了 Bash 脚本中的循环、重定向、管道和文件操作机制啦。以下是对本章的总结：

**循环语法**：

- `for` 循环：标准列表遍历和 C 风格两种形式
- `while` 循环：条件驱动的循环结构
- 循环控制：`break` 和 `continue`
- 变量作用域：注意子 shell 的影响

**重定向机制**：

- 基本重定向符号：`>`、`>>`、`<`、`2>`、`&>`
- 进程替换：`<()` 和 `>()`
- Here 文档：`<<`
- 文件描述符：0(stdin)、1(stdout)、2(stderr)

**管道机制**：

- 基本语法：`command1 | command2 | command3`
- 配合 `xargs` 处理管道输出
- 使用 `tee` 实现数据分流
- 错误处理使用 `set -o pipefail`

**文件操作**：

- 文件读取：`cat`、`head`、`tail`
- 文件写入：`echo`、`printf`、`tee`
- 权限管理：`chmod`、`chown`、`chgrp`
- 目录操作：`mkdir`、`cd`、`ls`、`cp`、`mv`、`rm`

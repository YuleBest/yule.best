## 一、变量

Shell 编程中，变量是用于存储数据值的名称。在生活中，我们用碗盛饭，碗可以类比为变量，而饭则是变量中存储的数据。

### 1 定义变量

定义变量时，我们使用「变量名=变量值」的语法。例如：

```bash
user_name=yule # 等号两边不能有空格
```

此处的变量名只能使用英文字母、下划线 `_` 和短横线 `-` 来命名，并且不能使用 Shell 内建的一些关键字，比如 `if`、`then`、`fi`、`for` 等。这些在后面会有介绍。

此处的变量值为字符串，虽然在没有空格、特殊符号的情况下，可以不使用双引号 `"` 包裹，但在实践中，一般我们会给他加上双引号：

```bash
user_name="yule best"
```

但如果变量值为整数时，则可以不加：

```bash
user_id=1001
```

你也可以使用单引号来定义，但这样的话，内部的所有字符（包括变量）都会被识别为字符串：

```bash
str="hello ${world}"
echo "$str" # 输出 hello ${world}
```

需要注意的是，Shell 中只有一种数据类型，就是字符串，其他的看似像数据类型的，比如整数、数组（下文介绍）等，均为字符串的包装版本。

你也可以使用命令的标准输出来作为变量值，语法是「变量名=$(命令)」。例如：

```bash
text="$(echo "hello")"
```

变量是可以被多次赋值的，你可以这样：

```bash
a=1
a=2
```

这样是合法的，但对于只读变量来说不合法。

### 2 定义只读变量

只读变量，是指不能再被赋值的变量。使用 `readonly 变量名` 将已赋值的变量更改为只读变量，使用 `readonly 变量名=变量值` 定义一个只读变量：

```bash
a=10
readonly a # 此时a不能再被赋值了
a=20 # 尝试再次赋值会报错

readonly b="hello" # 这样也可以哦
```

### 3 读取变量

使用 `$变量名` 读取一个已被赋值的变量：

```bash
name="yule"
echo $name
echo ${name} # 或者这样
```

变量名外侧的 `{花括号}` 在一般情况下是可选的，但在某些情况下必须加，比如变量名和字符串连在一起的情况下：

```bash
echo "${path}name"
```

如果不加，Shell 会以为你要使用 `pathname` 变量，这明显是不对的。

另外，Bash 还有几种变量展开语法，用于对变量值做一些处理后再使用，包括：

**a. 获取字符串长度**

```bash
str="1234"
echo "${#str}" # 输出4
```

**b. 提取子字符串**

::: warning 注意
第 1 字符的索引为 0
:::

```bash
str="yule is so cool"
echo "${str:5:2}" # 从第6字符开始读取2字符，输出is
```

### 4 移除变量

使用 `unset 变量名` 来移除变量，变量被移除之后，除非再次定义，否则它不能被使用。`unset` 不能移除只读变量：

```bash
name="yule"
unset name
echo -n "$yule" # 输出为空
```

## 二、数组

数组并不单纯是“多个数”的意思，数组是一种数据结构，用于存储多个元素。

### 1 定义数组

与大部分编程语言类似，数组元素的下标由 0 开始。Shell 数组用括号来表示，元素用空格分隔开，语法格式如下：

```bash
array=(值1 值2 值3 值4 ...)
```

比如这样：

```bash
fruits=("apple" "banana" "grape" "orange")
```

也可以使用数字下标来定义数组，这两个例子是等价的：

```bash
fruits[0]="apple"
fruits[1]="banana"
fruits[2]="grape"
fruits[3]="orange"
```

### 2 读取数组

读取数组里面的元素值的格式是：`${数组名[下标]}`。

由于数组的下标是从 0 开始的，所以第 N 个元素的下标是 `N-1`，这里需要注意。

```bash
fruits=("apple" "banana" "grape" "orange")
echo "我爱吃的水果有：${fruits[0]}、${fruits[1]}、${fruits[2]} 和 ${fruits[3]}。"
```

这个例子会输出：`我爱吃的水果有：apple、banana、grape 和 orange。`

数组和变量一样，也有一些特殊语法，用于快速读取数组。

使用 `${数组名[@]}` 可以读取数组的所有元素：

```bash
fruits=("apple" "banana" "grape" "orange")
echo "${fruits[@]}" # 输出 apple banana grape orange
```

使用 `${#数组名[数组下标]}` 可以获取元素的字符串长度，使用 `${#数组名[@]}` 可以获取数组的长度（即元素的个数）：

```bash
echo "${#fruits[0]}" # apple 长度为 5，所以会输出 5
echo "${#fruits[@]}" # 数组长度为 4，所以会输出 4
```

### 3 关联数组

关联数组是一种特殊的数组，它允许你使用任意的字符串作为下标来使用数组元素。关联数组使用 `declare -A` 命令来声明，语法格式如下：

```bash
declare -A 数组名
```

声明关联数组后，你就可以使用普通的数组语法对其进行操作。

举个例子：

```bash
declare -A user
user["name"]="于乐Yule"
user["age"]=18
user["hobby"]="Shell"
```

你也可以直接在声明时定义数组：

```bash
declare -A user=(["name"]="于乐Yule" ["age"]=18 ["hobby"]="Shell")
```

访问关联数组时，你需要使用元素的下标进行访问：

```bash
echo "用户是 ${user["name"]}" # 输出 用户是 于乐Yule
```

使用 `${!数组名[@]}` 可以获取关联数组的所有键：

```bash
echo "${!user[@]}" # 输出 name age hobby
```

使用 `${数组名[@]:起始下标:元素个数}` 进行数组的切片，元素个数可以使用负数：

```bash
echo "${user[@]:1:2}" # 取从下标1开始的2个元素
echo "${user[@]: -2}" # 取最后两个元素
echo "${user[@]: 2}"  # 取两个元素，注意 : 后要有空格
```

### 4 数组的增删改

要往已定义数组中追加或修改元素，可以直接使用 `数组名[下标]` 对其进行覆盖：

```bash
fruits=("apple" "banana" "grape" "orange")
fruits[1]="watermelon" # 覆盖下标 1 元素
fruits[4]="strawberry" # 追加下标 4 元素
echo "${fruits[@]}"
```

你也可以使用 `+=` 语法来追加数组：

```bash
fruits+=("peach")
```

这样会在数组的末尾追加一个新元素。同样的，如果你有两个数组，想把它们合为一个，也是使用此语法：

```bash
num_a=(1 2 3 4)
num_b=(5 6 7 8)
num_a+=("${num_b[@]}")
```

这会将 `num_b` 数组的所有元素追加到 `num_a` 数组的末尾。

## 三、基本运算符

Shell 支持很多运算符，包括：算术运算符、关系运算符、逻辑运算符、文件测试运算符等，其中本章讲解的是前三种，文件测试运算符会留到后面的教程再详细讲。

### 1 算术运算符

Bash 的算术运算包括 `+` 加法、`-` 减法、`*` 乘法、`/` 整数除法、`%` 求余数以及 `**` 幂运算。

你可以使用 `$((算术))` 进行简单的运算，在算术内，运算符的两边建议有空格，变量前面的 `$` 是可选的：

```bash
a=10
b=20

echo $((a + b)) # 10+20=30
echo $((b - a)) # 20-10=10
echo $((a * b)) # 10*20=200
echo $((b / a)) # 20/10=2
echo $((b % 3)) # 20/3=6 余下 2
echo $((2 ** 3)) # 2 的 3 次方=8
echo $((1 + 2 * 3)) # 输出 7
```

### 2 关系运算符

关系运算符是用来比较两个元素之间的关系的。

#### A 整数关系

如果你在处理整数（比如刚才的 `a=10`, `b=20`），你有两套方案：

**方法一：使用 `((...))` (推荐)**

这是最符合直觉的方式。在 `(( ))` 内部，你可以直接使用标准的数学符号。

| 符号 | 含义     | 例子         |
| :--- | :------- | :----------- |
| `==` | 等于     | `((a == b))` |
| `!=` | 不等于   | `((a != b))` |
| `>`  | 大于     | `((a > b))`  |
| `<`  | 小于     | `((a < b))`  |
| `>=` | 大于等于 | `((a >= b))` |
| `<=` | 小于等于 | `((a <= b))` |

举个例子，由于 `b` 确实大于 `a`，所以此例子会输出 `yes`。这里的 `if` 语句后续将会学习：

```bash
a=10
b=20
if ((b > a)); then
    echo "yes"
else
    echo "no"
fi
```

**方法二：使用 `[...]` 或 `[[...]]`**

这种方法需要使用字母缩写，且变量名前必须加 `$`。

| 符号  | 全称          | 含义     |
| :---- | :------------ | :------- |
| `-eq` | Equal         | 等于     |
| `-ne` | Not Equal     | 不等于   |
| `-gt` | Greater Than  | 大于     |
| `-lt` | Less Than     | 小于     |
| `-ge` | Greater Equal | 大于等于 |
| `-le` | Less Equal    | 小于等于 |

在大部分新版本 Bash 中，`[[ 算术 ]]` 也支持使用数学符号的表达法。

```bash
a=10
b=20
if [[ $b > $a ]]; then
    echo "yes"
else
    echo "no"
fi
```

#### B 字符串关系

在处理字符串（比如判断 `user == "Yule"`）时，必须使用这套运算符。

字符串比较建议统一使用 `[[ ... ]]`（双中括号），因为它比单中括号更安全，不需要担心变量为空导致的语法错误。

- `==` 或 `=` 判断元素相等：`[[ $name == "Yule" ]]`
- `-z` 判断字符串为空：`[[ -z "$empty_var" ]]`
- `-n` 判断字符串不为空：`[[ -n "$name" ]]`

### 3 逻辑运算符

在 Bash 中可以进行逻辑运算。

- 使用 `||` 或者 `-o` 进行“或”运算。下面的例子意思是“如果 `a` 大于 `b` 或大于 `c`，输出 `yes`，否则输出 `no`”：

```bash
a=2
b=1
c=3

if [[ $a -gt $b || $a -gt $c ]]; then
    echo "yes"
else
    echo "no"
fi
```

- 使用 `&&` 或者 `-a` 进行“与”运算。下面的例子意思是“如果 `a` 大于 `b` 并且大于 `c`，输出 `yes`，否则输出 `no`”：

```bash
if [[ $a -gt $b && $a -gt $c ]]; then
    echo "yes"
else
    echo "no"
fi
```

- 使用 `!` 进行“非”运算。下面的例子意思是“如果 `a` 大于 `b` 并且不等于 `c`，输出 `yes`，否则输出 `no`”：

```bash
if [[ $a -gt $b && $a != $c ]]; then
    echo "yes"
else
    echo "no"
fi
```

逻辑运算的执行顺序是：`!` (非) > `&&` (与) > `||` (或)。 如果你需要改变优先级，可以使用圆括号：

```bash
# 如果 (A 且 B) 或者 C
if [[ ($name == "Yule" && $role == "admin") || $status == "root" ]]; then
    echo "Access granted"
fi
```

**短路求值**：`&&` 和 `||` 这两个运算符具有“短路”特性，这在写单行命令时极其有用：

- `A && B`：只有 `A` 成功了，才会执行 `B`；
- `A || B`：只有 `A` 失败了，才会执行 `B`。

## 四、条件判断语句（`if` 和 `case`）

Bash 的条件判断主要有三种结构：`if`（最常用）和 `case`（多分支逻辑）。

### 1 `if ... then ... fi` 结构

这是最基础的逻辑判断。Bash 的语法特点是：每一个 `if` 必须以 `fi` 结尾（就是 `if` 反过来写）。

```bash
if [[ 条件A ]]; then
    # 如果条件为真执行
elif [[ 条件B ]]; then
    # 如果另一个条件为真执行
else
    # 以上都不满足时执行
fi
```

这里的 `elif` 和 `else` 是可选的，你可以直接：

```bash
if [[ 条件A ]]; then
    # 条件为真时执行
fi
```

如果 `then` 和 `if` 写在同一行，必须加分号：`if [[ ... ]]; then`。 如果 `then` 另起一行，则不需要分号。

### 2 `case ... esac` 结构

如果你有大量的 `elif`，代码会变得很难看。这时候 `case` 就派上用场了，它类似于其他语言的 `switch`。

`case` 语法中，每个分支的操作使用 `;;` 结尾。每个分支条件以右括号 `)` 结尾。整个结构使用 `esac` 结束。

```bash
case "$str" in
    "a")
        echo "str 为 a"
        ;;
    "b" | "c") # 使用 | 表示“或”
        echo "str 为 a或b"
        ;;
    *) # 相当于 else
        echo "str 为 其他"
        exit 1
        ;;
esac
```

## 五、函数

Bash 函数本质上是“带名字的命令组”。

### 1 函数的定义

定义函数有两种语法，效果完全一样：

**方式 A：现代写法（推荐）**

```bash
function_name() {
    # 代码逻辑
    echo "Hello, $1"
}
```

**方式 B：显式声明（老派）**

```bash
function function_name {
    # 代码逻辑
    echo "Hello, $1"
}
```

在 Bash 中，函数必须**先定义、后调用**。

### 2 函数的调用

调用时直接跟在函数名后面，参数用空格隔开。Bash 函数不能在括号里定义参数（比如 `func(a, b)` 是不行的）。它通过位置参数来接收输入：

```bash
function_name "yule" "best"
```

例子：

```bash
get_sum() {
    echo $(( $1 + $2 ))
}
result=$(get_sum 10 20) # result 得到 30
```

### 3 返回值

在大多数语言中，`return` 返回的是计算结果；但在 Bash 中，`return` 返回的是**退出状态码**（0-255）。

- `return 0`：表示函数执行成功。
- `return 1`（非零）：表示出错了。

### 4 变量作用域

默认情况下，Bash 函数里的变量都是全局的。这意味着如果你在函数里改了一个变量，函数外面也会跟着变。

可以在函数内使用 `local` 关键字来限制变量的作用域：

```bash
test_scope() {
    local name="Local Yule" # 函数内才有效
    echo "Inside: $name"
}
```

### 5 间接传递

如果你想把一个数组传进函数，你需要使用 `local -n`，这相当于“传引用”。

```bash
process_array() {
    local -n current_arr=$1   # current_arr 指向传入的变量名
    current_arr+=("NewTask") # 操作数组
}
```

### 6 应用建议

- **保持短小**：一个函数只做一件事（比如专门负责日志打印、专门负责检查环境）。
- **错误处理**：在函数内部判断失败后及时 `return 1`。
- **注释说明**：写清楚参数 `$1`、`$2` 分别代表什么。
